The public folder contains aggregate results and illustrations. It excludes individual observations, command traces and timing samples. Reproduce the report's tables and timing summaries using the private evaluation-data ZIP and the command in the root README. These are single-participant, non-blind functional results. The teacher submission also includes actual detected-joint hand stills, a sample command trace, the report appendix, presentation and backup clips. Full personal camera images and videos are not included in this public folder.
